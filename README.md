# 📚 مكتبة معهد القاهرة العالي

موقع مكتبة إلكترونية لمعهد جامعي: بوابة دخول للطلاب والمسؤول، والطالب **لازم يكون دافع المصروفات** علشان يفتح الكتب.

## المميزات
- **بوابة دخول موحدة** (طالب / مسؤول) بجلسات PHP وتشفير bcrypt لكلمات السر.
- **موقع الطالب:** بياناته، وتغيير كلمة السر، ومكتبة الكتب (مقفولة لو مدفعش).
- **موقع المسؤول:** إضافة وحذف الطلاب، وتسجيل الدفع أو إلغاؤه، وفلتر الدافعين وغير الدافعين، وإحصائيات، ورفع الكتب (PDF أو رابط) وحذفها، وتصدير SQL.
- **حماية الكتب على السيرفر:** الكتب بتتقدم من `api.php` بعد فحص السداد من الداتا بيز، والوصول المباشر لفولدر `books/` ممنوع.

## التقنيات
HTML + CSS + JavaScript (ملف واحد `index.html`) • PHP 8+ (PDO) • MySQL / MariaDB • Tailwind CDN • Font Awesome • خط Cairo

## هيكل المشروع
```
├── index.html          # الواجهة كلها: الدخول + الطالب + المسؤول
├── api.php             # الـ Backend
├── config.sample.php   # نموذج إعدادات الداتا بيز (انسخه باسم config.php)
├── database/
│   ├── 01_database.sql # قاعدة البيانات وجدول الطلاب (بيانات تجريبية)
│   ├── 02_admins.sql   # جدول المسؤولين
│   └── 03_library.sql  # أعمدة الدفع وجدول الكتب
└── books/              # الكتب المرفوعة (محمي بـ .htaccess)
```

## التشغيل محليًا (XAMPP أو أي سيرفر PHP)
1. حط المشروع في `htdocs/` (أو جذر السيرفر).
2. استورد ملفات `database/` بالترتيب (01 ثم 02 ثم 03) في phpMyAdmin.
3. انسخ `config.sample.php` باسم `config.php` وعدّل بيانات MySQL.
4. (اختياري) حط شعار المعهد باسم `chi-logo-1.png` جنب `index.html`.
5. افتح `http://localhost/<اسم-الفولدر>/`.

## الحسابات التجريبية
| النوع | اسم المستخدم | كلمة السر |
|---|---|---|
| مسؤول | `admin` | `Admin#2026` |
| طالب (دافع) | `abdalla_g` | `Pass#202401` |
| طالب (غير دافع) | `omar_k` | `Pass#202404` |

> كلمات السر دي للتجربة بس. **غيّرها قبل أي نشر حقيقي.** أول تسجيل دخول بيحوّل كلمة السر لـ bcrypt تلقائيًا.

## ملاحظات مهمة
- **GitHub Pages مش بيشغّل PHP.** GitHub هنا لحفظ الكود بس. للتشغيل أونلاين محتاج استضافة بتدعم PHP وMySQL.
- لو هتنشر على استضافة: فعّل HTTPS، وغيّر بيانات `config.php`، وتأكد إن Apache بيقرأ ملفات `.htaccess`.
- لو المشروع على Nginx، امنع الوصول لـ `books/` و`database/` و`config.php` من إعدادات السيرفر.
- حجم رفع الكتب محدود بـ `upload_max_filesize` و`post_max_size` في `php.ini`.
- المشروع مفيهوش حماية CSRF وتحديد محاولات الدخول، فيفضل إضافتهم قبل استخدامه في بيئة حقيقية.
